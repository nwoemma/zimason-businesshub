# Zimason BusinessHub — Frontend Demo

This is a frontend-only prototype for Zimason BusinessHub.

Tech:
- React + TypeScript (Vite)
- Redux Toolkit for centralized state
- Tailwind CSS for styling
- LocalStorage persistence (seeded demo data)

Run:
1. npm install
2. npm run dev
3. Open http://localhost:5173

Notes:
- Admin area: /admin (inventory, dashboard, settings)
- Customer area: / (home, products, product detail)
- Reset demo data in Admin → Settings (or clear localStorage keys starting with `zimason:`)
